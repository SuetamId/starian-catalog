# Plano — Spec 002 CRUD de produtos

## Fase 1 — Acesso a dados
- Criar modelo e payload de produto.
- Criar serviço de API de produtos.
- Criar testes do serviço para GET, POST, PUT e DELETE.

## Fase 2 — Estado da feature
- Criar store baseado em Signals.
- Carregar produtos e categorias.
- Criar Signal derivado de produtos filtrados.
- Implementar reconciliação de mutações.
- Criar testes do store para transições de carregamento, sucesso e erro.

## Fase 3 — Experiência de leitura
- Criar página de listagem.
- Criar tabela responsiva e cards mobile.
- Adicionar busca e filtro de categoria.
- Adicionar estados de carregamento, erro, vazio e vazio filtrado.

## Fase 4 — Criar e editar
- Construir formulário reativo reutilizável.
- Criar página de cadastro.
- Criar página de edição.
- Adicionar testes de validação.

## Fase 5 — Excluir
- Criar dialog de confirmação.
- Integrar exclusão.
- Adicionar testes de confirmação e cancelamento.

## Fase 6 — Refinamento
- Adicionar feedback visual.
- Adicionar fallback de imagem.
- Revisar acessibilidade mínima.
- Revisar layout responsivo.
- Remover código morto.

## Fase 7 — Entrega
- Executar lint, testes e build de produção.
- Preencher documento de revisão.
- Atualizar README.
- Adicionar screenshots se útil.
- Atualizar estado atual.
