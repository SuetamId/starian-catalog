# Início rápido — Spec 002 CRUD de produtos

## Antes de começar
- Confirmar que a revisão da Spec 001 foi concluída.
- Ler `AGENTS.md`.
- Ler `docs/ESTADO_ATUAL.md`.
- Ler integralmente esta pasta de especificação.

## Regra de implementação
Implementar somente dentro de `features/admin/products` (P0). Não criar pastas de `features/store/*` nesta spec.

Construir primeiro o menor fluxo completo:
1. GET de produtos;
2. estado de carregamento no store;
3. estados da página de listagem;
4. criação;
5. edição;
6. exclusão;
7. refinamento e testes.

Não iniciar melhorias opcionais antes de concluir os critérios obrigatórios.
